# Technology Stack: LOB Modeling

## Core Language
*   **Python**: The primary programming language for all model implementations, utilities, and notebooks.

## Numerical & Scientific Computing
*   **NumPy**: Used for efficient numerical arrays and mathematical operations.
*   **SciPy**: Provides optimization, statistical, and other scientific computing functions.
*   **Scikit-Learn**: Used for machine learning and statistical modeling.
*   **Statsmodels**: Provides classes and functions for the estimation of many different statistical models.

## Data Analysis & Manipulation
*   **Pandas**: The primary library for data manipulation, analysis, and cleaning.

## Data Visualization
*   **Matplotlib**: The primary library for creating static, animated, and interactive visualizations.

## External Data
*   **yfinance**: Used for fetching historical market data.

## Testing & Quality
*   **Pytest**: (Inferred) The preferred framework for unit and integration testing.

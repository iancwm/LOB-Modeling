# Technology Stack: LOB Modeling

## Core Language
*   **Python**: The primary programming language for all model implementations, utilities, and notebooks.

## Package Management
*   **uv**: Fast Python package installer and resolver (recommended)
*   **pip**: Traditional Python package installer (compatible)

## Development Tools
*   **just**: Command runner (replacement for Makefile)
*   **black**: Code formatting
*   **flake8**: Code linting
*   **isort**: Import sorting
*   **pydocstyle**: Docstring style checking
*   **mypy**: Static type checking
*   **pytest**: Testing framework
*   **pytest-cov**: Coverage reporting
*   **pytest-asyncio**: Async test support

## Numerical & Scientific Computing
*   **NumPy**: Numerical computing
*   **SciPy**: Scientific computing and optimization
*   **Scikit-Learn**: Machine learning utilities
*   **Statsmodels**: Statistical modeling

## Data Analysis & Manipulation
*   **Pandas**: Data manipulation and analysis

## Data Visualization
*   **Matplotlib**: Static visualizations
*   **Plotly**: Interactive visualizations

## External Data
*   **yfinance**: Market data fetching

## Web Framework
*   **FastAPI**: Modern web framework for APIs
*   **Uvicorn**: ASGI server
*   **Websockets**: WebSocket support

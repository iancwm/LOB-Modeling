# Track Specification: Standardize Model Documentation and Code Standards

## Goal
Standardize the documentation and code style for all market making models to match Google's Python style guide.

## Requirements
- Update docstrings for all models in `src/lob_modeling/models/` to Google style.
- Refactor code to follow Google's Python style conventions (naming, formatting, etc.).
- Ensure consistent parameter handling and error checking across all models.
- Update the main README and example notebooks to reflect the changes.

## Success Criteria
- All models have Google-style docstrings.
- Code passes a linter with Google style configuration.
- Tests pass and cover all core model logic.
- Documentation is clear, accurate, and helpful for new users.
